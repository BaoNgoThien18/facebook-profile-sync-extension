User API Token (BugLab Fb Sheet)

Lấy token từ trang Web facebook.buglab.vn mục "Tài khoản & API Token" rồi dán vào đây.

Khi có token này, mỗi lần bạn nhấn "Đồng bộ ngay", các Profile và Page sẽ được tự động gán cho bạn và Leader trực tiếp phụ trách.
